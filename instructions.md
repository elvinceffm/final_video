Assignment Description

For the final project, your team will choose a dataset from Kaggle and use R/RStudio to build a simple K-Nearest Neighbors classification model .

The purpose of this project is to practice working with real data, preparing a dataset, creating or selecting a categorical target variable, building a KNN model, and explaining the results clearly.

This is a team project . Each team should have 3 students (less than 3 is not acceptable) .
Dataset Requirement

Your team must choose one dataset from Kaggle.

The dataset should have:

    At least 100 rows

    Several useful variables for prediction

    One clear target variable

    A target variable that is categorical

Examples of categorical target variables include:

    Yes / No

    Survived / Did not survive

    Approved / Not approved

    Sick / Not sick

    High / Low

    Good / Bad

    Churn / No Churn

If the target variable is numeric, your team may convert it into categories. For example, a price variable could be changed into “High” and “Low.”
Suggested Kaggle Dataset Topics

Your team can choose any simple dataset from Kaggle. Suggested topics include:

Choose a dataset that your team can understand and explain clearly.
Project Tasks

Your team should complete the following tasks:

    Choose and download a dataset from Kaggle.

    Load the dataset into R/RStudio.

    Explore the dataset by checking the rows, columns, variable names, and data types.

    Choose the target variable that your team wants to predict.

    Make sure the target variable is categorical.

    Clean the dataset. For example, remove missing values ​​and remove unnecessary columns such as ID numbers or names.

    Split the dataset into training data and test data.

    Build a KNN classification model.

    Use the model to make predictions on the test data.

    Evaluate the model using a confusion matrix and accuracy.

    Explain what the results mean in simple words.

Video Presentation Requirements

Each team must record a video presentation.

The video should be 5 minutes long (5:20 sec will be rejected) .

Each team member must speak in the video.

In the video, your team should explain:

    The name of the Kaggle dataset you selected

    Why your team selected this dataset

    What the dataset is about

    What the target variable is

    What variables you used to predict the target

    What data cleaning you completed

    How to split the data into training and test data

    How KNN works in simple words

    The value of k selected by the model

    The confusion matrix results

    The accuracy of the model

    What your team learned from the project

You can record your screen and show your RStudio code, dataset, model output, and results.
